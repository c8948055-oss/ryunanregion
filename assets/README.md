# Ryunan image assets

This directory is the destination for the optimized WebP images supplied for the Ryunan guide.

Expected filenames:
- `professor-takahashi.webp`
- `professor-tsukishiro.webp`
- `professor-kurosawa.webp`
- `professor-hanazawa.webp`
- `professor-hoshizora.webp`
- `professor-minazuki.webp`
- `professor-iwasaki.webp`
- `professor-midorikawa.webp`
- `institute-takahashi.webp`
- `institute-tsukishiro.webp`
- `institute-kurosawa.webp`
- `institute-hanazawa.webp`
- `institute-hoshizora.webp`
- `institute-minazuki.webp`
- `institute-iwasaki.webp`
- `institute-midorikawa.webp`
- `kurogane-hq.webp`

The original site source identified these image files as a separate ZIP bundle. They were not present in the Git repository history and must be copied into this directory to display the corresponding gallery images.

The official world/region maps, Gym Leader portraits and architecture, Elite Four portraits, and Champion art were not present in that image set. Their placeholders in the guide are intentional.
