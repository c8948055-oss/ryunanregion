# Pokémon Ryunan — Website package

Gói website tĩnh hoàn chỉnh, gồm `index.html` và toàn bộ ảnh WebP trong `assets/`.

## Chạy thử
Mở `index.html` bằng trình duyệt. Không cần cài đặt hoặc build.

## Cập nhật GitHub Pages
Giải nén ZIP này, sau đó tải **cả `index.html` và thư mục `assets/`** lên thư mục gốc của repository `c8948055-oss/ryunanregion`, ghi đè `index.html` cũ và bổ sung/ghi đè các tệp trong `assets/`. Không chỉ tải riêng `index.html`, vì các ảnh được gọi bằng đường dẫn tương đối `assets/*.webp`.

## Ảnh được tích hợp
- Bản đồ thế giới và bản đồ vùng Ryunan.
- 8 Giáo sư và 8 viện nghiên cứu.
- 8 công trình Hội quán và 8 chân dung Chủ hội quán (bản ảnh mới).
- 4 chân dung Tứ Đại Thiên Vương.
- Trụ sở Kurogane Group.

Ảnh Nhà Vô Địch chưa có trong bộ tư liệu được cung cấp nên khu vực đó vẫn giữ phần giới thiệu chữ.
