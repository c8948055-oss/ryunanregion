# Pokémon Ryunan — Regional Guide

A static Vietnamese encyclopedia and travel guide for the fictional Pokémon Ryunan region.

## Run locally
Open `index.html` in a browser. No build tooling is required.

## Images
Optimized WebP images belong in `assets/`. See [assets/README.md](assets/README.md) for the expected file names.

The historic site bundle referenced those binary images as a separate ZIP attachment. They were not stored in the previous Git repository, so they cannot be restored from Git history alone.

## Content conventions
- Preserve the supplied Vietnamese region guide content and naming.
- Route number groups are listed, while exact origins, destinations, and waypoints remain pending a canonical route map.
- Missing map, Gym Leader, Gym architecture, Elite Four, and Champion images remain placeholders rather than fabricated or externally sourced art.
